# GT7 Engineer Board – Downloads

> **Geschlossene Beta.** Das GT7 Engineer Board wird derzeit nur innerhalb einer geschlossenen Testgruppe
> (BpV Racing League) erprobt. Die Online-Liga-Funktionen sind ausschließlich mit Einladungscode nutzbar.
> Es gibt keinen Support für Nutzer außerhalb der Testgruppe; Funktionen und Daten können sich jederzeit ändern.

Live-Boards für Gran Turismo 7 am PC: Delta, Strategie, Kurven-Tipps, Sprachausgabe über Discord
und Online-Vergleich mit deiner Liga. Dieses Repository enthält nur die Installationsdateien.

**[Neueste Version herunterladen](../../releases/latest)** – dort `GT7-Engineer-Board-Setup-x.y.z.exe` wählen.

## Installation
1. Setup herunterladen und starten.
2. Windows warnt „Der Computer wurde durch Windows geschützt“ (das Setup ist nicht signiert):
   **Weitere Informationen → Trotzdem ausführen**.
3. Keine Administratorrechte nötig. Haken „Firewall-Regeln anlegen“ drin lassen.
4. Start über die Verknüpfung **GT7 Engineer Board**.

## Beim ersten Start
Ein Einrichtungsassistent führt durch PS5-Verbindung, Sprachausgabe (eigener Discord-Bot, optional)
und Online-Liga (Discord-Anmeldung + Einladungscode vom Liga-Admin, optional).
Was jedes Board kann: Board-Auswahl → **? Anleitung**.

Voraussetzungen: Windows 10/11, Microsoft Edge, PC und PS5 im selben Netzwerk.
